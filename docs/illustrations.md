# Картинки-истории

Короткие «комиксы» на 2–4 кадра. Каждый объясняет одно правило картинкой: что происходит, почему форма такая и как не ошибиться. Пользователь — визуал, поэтому картинка должна объяснять сама: подпись только подтверждает то, что уже видно. Эталон — `src/illustrations/stories/pron-personal.tsx`.

## Где показываются

- **Тема** — блок «Картинки» сверху справочника, все истории темы.
- **Знакомство с новой темой** — первая история.
- **Разбор ответа** — после ошибки сама раскрывается история, у которой в `focus` есть ключ навыка (или его часть: для `obj.he` подойдут и `obj`, и `he`). После верного ответа её можно открыть кнопкой «Почему — картинкой».

## Формат

`src/illustrations/stories/<id темы>.tsx`, `export default [ … ] satisfies TopicStories` (типы — `src/illustrations/types.ts`):

```tsx
{
  id: 'articles.a-then-the',            // <тема>.<slug>
  title: 'a → the: сначала «какой-то», потом «тот самый»',
  focus: ['a', 'the', 'q-known'],       // ключи схемы темы из src/visuals/catalog.ts
  frames: [
    { scene: <Scene label="…">…</Scene>, en: 'I_P saw_V {a_D} dog_N .', ru: 'Одна из многих собак — a.' },
    …
  ],
}
```

- 1–3 истории на тему, у каждой 2–4 кадра. Одна история — одно правило.
- Ставь `focus`, чтобы история находилась при ошибке на навыке.
- `en` — подпись в мини-разметке, ровно одна `{цель}` (она подсвечивается). Предложение естественное, британское, уровня A1–B1. `ru` — 1–2 короткие фразы: что видно и почему так. Для русского примера ставь `lang: 'ru'`.
- Хорошая структура: 1) обычный случай, 2) контраст (то же, но иначе — и форма меняется), 3) ловушка русского или исключение. Последний кадр отвечает на вопрос из заголовка.

## Набор (`src/illustrations/kit`)

Рисуем только набором. Своих SVG-путей в истории — минимум, и только мелочи.

| Что | Как |
|---|---|
| `Scene` | холст 320 × 200, пол на `GROUND` (y = 168). `label` — что на картинке, для озвучки. `ground={false}` — без пола |
| `Person` | человечек, ноги в (x, y), рост ~72 при `s=1`. `pose`: stand, walk, run, sit, point, think, talk, wave, hold, give, look, sleep. `flip` — смотрит влево. `tone` 0–3 — разные люди. `hair` short/long — он или она без цвета. `hl` + `pos` — выделить |
| `Prop` | предмет из `PROPS` по английскому имени, низ по центру в (x, y). `s` — масштаб, `hl` + `pos` — выделить, `dim` — приглушить. Каталог — на `#/kit` |
| `Many` | ряд одинаковых предметов, `hlIndex` — какой выделен (остальные приглушены) |
| `Arrow` | `tone="action"` — **действие (глагол)**: от того, кто делает, к тому, на что направлено; `motion` — путь движения; `ink`/`dim` — связи. `label` — глагол |
| `Bubble` | речь или мысль; внутри — `Label` или предметы |
| `Label` | короткая подпись в сцене, с `pos` — цветом части речи |
| `Spot`, `Frame` | кольцо или рамка выделения («тот самый», «группа», «период») |
| `Cross`, `Check` | так нельзя / так правильно |
| `At` | сдвиг и масштаб группы |

Нужного предмета нет — добавь его в свой файл `src/illustrations/kit/extra/<раздел>.tsx`: `export const EXTRA: Record<string, PropDef> = { … }`. Имя — английское слово и уникальное, стиль как в `props.tsx`. `PROPS` подхватит файл сам.

## Визуальный язык

1. **Цвет = часть речи, и только.** Люди и предметы нейтральные. Цветом выделено ровно одно — то, о чём правило, в цвете его части речи (`pos`). Стрелка-действие — цвет глагола.
2. **Глагол — стрелка.** Та же метафора, что в графе предложения: кто делает — у начала стрелки, на что направлено — у конца. Время — ось слева направо с NOW, как в схеме `timeline`.
3. **Смысл, а не украшение.** Никаких декоративных деталей, фонов и пейзажей ради красоты: каждая линия что-то объясняет. Лишнее мешает учиться (seductive details).
4. **Подписи рядом с объектом**, 1–3 слова. Длинный текст — в `ru` под картинкой, не в сцене.
5. **Контраст кадров.** Соседние кадры отличаются ровно тем, что меняет форму (сменилось направление стрелки — сменилась форма).
6. Крупно и читаемо на телефоне (311 px): главные фигуры крупные, `s` 1.2–1.6, текст в сцене не мельче 11.
7. Без анимации: кадры листает человек.

## Проверка

1. `npx tsc --noEmit` — без ошибок.
2. Скриншоты каждого кадра: `fnm exec --using=24 -- node tools/shot.mjs "http://localhost:<порт>/#/stories/<тема>?s=<история>&f=<кадр>" out.png 390 560`. Вся тема целиком — `#/stories/<тема>`, набор — `#/kit`.
3. Смотри глазами. Понятно ли правило без подписи? Одно ли выделение? Не обрезано ли? Верна ли грамматика?
