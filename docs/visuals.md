# Как делать схему

Схема — главный визуальный якорь темы: она стоит в справочнике и возвращается мини-версией после каждого ответа с подсветкой нужного места. Образец — `src/visuals/grid/PronGrid.tsx` + `grid.css`. Что рисовать — поле `desc` в `src/visuals/catalog.ts`; ключи подсветки — поле `focus` там же. Каталог не меняем.

## Подключение

- Папка семьи `src/visuals/<папка>/`: компоненты, свой CSS (`<папка>.css`) и `index.ts` с `export default { 'id': Component } satisfies VisualFamilyModule`. CSS импортируется в `index.ts`. Реестр подхватит папку сам (`src/visuals/index.tsx`).
- Префикс классов уникален для папки (`vg-` у grid). Чужие классы не трогаем, глобальные стили не пишем.
- Компонент: `(props: VisualProps) => JSX`. Пропсы:
  - `focus` — ключ из каталога. Подсвечен только он; остальное приглушено (`--c3`, `--sep`), но читается. Без `focus` всё в обычном виде.
  - `compact` — мини-версия для разбора ответа: высота до ~140 px, только нужная часть (например, одна ячейка с соседями), без длинных подписей.
  - `quiz` — схема как вопрос: спрятать подписи, которые выдают ответ (название времени, формулу, слово в ячейке).
- Ключ `focus` может быть составным (`subj.he`), строкой или столбцом. Разбирай его так же, как `PronGrid`.

## Визуальный язык

- Только тёмная тема. Цвета — только токены кита (`--c1…--c4`, `--f1…--f6`, `--lv`, `--sep`, `--s1…--s3`) и цвета частей речи через `data-pos="<pos>"` на элементе: тогда доступны `--pc` (заливка, линии) и `--pt` (текст). Никаких hex и своих цветов.
- Цвет = часть речи. Часть речи всегда дублируется формой: компонент `Glyph` (`src/ui/Glyph.tsx`). Английские слова и примеры выводи через `Sentence` (`src/ui/Sentence.tsx`) с разметкой — так цвета совпадут с остальным приложением.
- Подписи прямо на элементе или рядом с ним, а не в легенде внизу. Русские подсказки короткие (2–4 слова).
- Одно выделение на экран: подсвеченный элемент — цвет части речи + обводка или фон `color-mix(in oklab, var(--pc) 22%, var(--lv))`. Жирный, подчёркивание и иконку одновременно не используем.
- Никаких декоративных иллюстраций, градиентов, теней ради красоты. Каждая линия несёт смысл.
- Шрифт — `var(--font-ui)`. Текст не мельче 12 px на ширине телефона.
- Скругления — `--r-card` у крупных блоков, 10–14 px у ячеек.

## Размеры и вёрстка

- Ширина 100 % контейнера. Должно влезать без горизонтальной прокрутки в 311 px (iPhone: 375 − отступы) и хорошо смотреться до 640 px.
- HTML и CSS grid для таблиц и слотов; SVG — для осей, траекторий, стрелок. У SVG `viewBox` около 320–360 единиц по ширине, чтобы 1 единица ≈ 1 px на телефоне. Текст в SVG — `fill="currentColor"` или `var(--pt)`, `font-family: var(--font-ui)`.
- SVG: `role="img"` и `aria-label` с кратким смыслом схемы.

## Движение

Статика по умолчанию. Анимация только там, где сама механика — движение (траектория предлога, перенос вспомогательного глагола в начало вопроса): до 1,2 с, по нажатию «▶ показать», без бесконечных циклов. Длительности — `--dur`, `--dur-slow`, пружина `--spring`. При `prefers-reduced-motion` и `--m-move: 0` — без перемещений, только проявление.

## Проверка

1. `npx tsc --noEmit` — без ошибок.
2. Запусти dev-сервер на своём порту: `npx vite --port <порт> --strictPort` (в фоне).
3. Сними скриншоты скриптом (headless Chrome сам не умеет окно уже ~500 px, скрипт эмулирует телефон):
   ```
   fnm exec --using=24 -- node tools/shot.mjs "http://localhost:<порт>/#/gallery/<id>?focus=<ключ>&view=full" /путь/out.png 390 900
   fnm exec --using=24 -- node tools/shot.mjs "http://localhost:<порт>/#/gallery/<id>?focus=<ключ>&view=compact" /путь/out-mini.png 390 600
   fnm exec --using=24 -- node tools/shot.mjs "http://localhost:<порт>/#/gallery/<id>?focus=&view=quiz" /путь/out-quiz.png 390 900
   fnm exec --using=24 -- node tools/shot.mjs "http://localhost:<порт>/#/gallery/<id>?focus=" /путь/out-desk.png 1024 900
   ```
   Скрипт печатает `overflow: true`, если страница шире экрана, — это ошибка. Открой PNG (скриншот в 2×) и посмотри глазами: ничего не обрезано, текст читается, подсветка одна, мини-версия компактная, в режиме quiz ответ не виден.
4. Пройди несколько разных ключей `focus` для каждой схемы: строку, столбец, ячейку.
