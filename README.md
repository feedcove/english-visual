# Грамматика в цвете

Личный тренажёр английской грамматики (и русских частей речи) на 10–15 минут в день. Цвет = часть речи, форма дублирует цвет, у каждой темы своя схема. Повторы по FSRS, всё работает офлайн.

## Каждое утро

**Mac, без установки.** После сборки открой `dist/grammar.html` двойным кликом. Это один файл без интернета и сервера. Положи его в Dock или в избранное браузера.

**Mac и iPhone как приложение (PWA)** — https://feedcove.github.io/english-visual/
- iPhone: открой адрес в Safari → «Поделиться» → «На экран Домой».
- Mac: Safari → «Файл» → «Добавить в Dock» (или Chrome → «Установить»).
После первого открытия приложение работает без сети. Новая версия скачивается в фоне при запуске с интернетом и видна со следующего открытия.

**Локально для разработки:** `npm run dev`, затем http://localhost:5173.

Прогресс хранится в браузере, на каждом устройстве свой. Перенос — «Настройки → Мои данные → Сохранить копию / Восстановить из файла». Сохраняй копию раз в неделю.

## Что внутри

- **Сегодня** — одна кнопка: повторы вперемешку → новая тема блоком → повтор нового вводом → скоростной раунд 45 с. Есть короткий режим на 5 минут, он тоже засчитывается в серию.
- **Картинки-истории** — 107 векторных «комиксов» (315 кадров) во всех темах: что, почему и как работает правило. Глагол — стрелка от того, кто действует, к тому, на что направлено; признак на предмете — прилагательное, на стрелке — наречие. После ошибки нужная картинка открывается сама. Как рисовать новые — `docs/illustrations.md`, набор фигур и предметов — `#/kit`, все истории — `#/stories`.
- **Темы** — 44 темы в 7 разделах: части речи (русские и английские), граф предложения, местоимения, существительные и артикли, глаголы и времена, прилагательные и наречия, предлоги, предложение. В каждой теме справочник: схема, правила, «как в русском», ловушки и озвучка.
- **Прогресс** — стадии навыков, 12 недель активности, точность, скорость, прогноз повторов, карта освоения, слабые места, проверка недели.
- **Мои предложения** — свой текст графом и лесенкой. Разбери текст парсером в формат CoNLL-U: на сайте [UDPipe](https://lindat.mff.cuni.cz/services/udpipe/) (модель russian-syntagrus или english-ewt, вывод CoNLL-U) или локально `python3 tools/parse.py --lang ru "текст"` (нужен spaCy: `python3 -m pip install spacy && python3 -m spacy download ru_core_news_sm`). Вставь результат в «Темы → Мои предложения». Разбор автоматический, это черновик.
- **Как устроено обучение** — методика и источники (подробно в `docs/research.md`).

## Разработка

Нужны Node.js 24 (`.node-version`) и npm. Зависимости ставятся с `legacy-peer-deps` (`.npmrc`): в npm 11 есть баг с опциональными peer-зависимостями `@vitejs/plugin-react`.

```sh
npm ci
npm run dev        # dev-сервер
npm run check      # TypeScript
npm test           # юнит-тесты + валидатор контента
npm run validate   # только контент
npm run build      # dist/ (PWA) + dist/grammar.html (один файл)
npm run smoke      # проходит занятие в headless Chrome (нужен запущенный dev-сервер)
npm run deploy     # собрать и выложить на GitHub Pages (ветка gh-pages)
```

Выкладка: `npm run deploy` собирает `dist/`, коммитит его в ветку `gh-pages` через временный worktree и пушит. Сайт обновляется примерно через минуту.

Стек: Vite 8, React 19, TypeScript, `ts-fsrs` (FSRS-6), собственный service worker (`vite.config.ts`). UI — токены и рецепты UI-кита (`src/styles/kit.css`, тёмная тема из движка кита в `tools/uikit-engine/`).

## Структура

- `src/content/` — модель (`types.ts`), паспорта тем (`catalog.ts`), разметка предложений (`sentence.ts`), граф (`graph.ts`), части речи (`pos.ts`), темы (`topics/<id>.ts`).
- `src/visuals/` — схемы тем по семьям, каталог id и ключей подсветки (`catalog.ts`).
- `src/engine/` — FSRS (`srs.ts`), сборка занятия (`session.ts`), хранилище (`store.ts`), статистика (`stats.ts`), проверка ответа (`check.ts`), озвучка (`tts.ts`).
- `src/exercises/` — форматы заданий: выбор, ввод, сборка, раскраска, поиск слова, граф, скоростной раунд, разбор ответа.
- `src/screens/` — экраны.
- `docs/authoring.md` — как писать тему; `docs/visuals.md` — как делать схему; `docs/research.md` — исследования.
- `tools/` — скриншоты и смоук-тест через Chrome DevTools Protocol, сборка одного файла, движок кита.
